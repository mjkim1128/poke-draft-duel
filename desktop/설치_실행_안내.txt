Poke Draft Duel (PC 버전) 설치 및 실행 안내
============================================

이 게임은 팬이 만든 비공식 게임입니다. 포켓몬과 관련된 이름, 그림의 저작권은
Nintendo / Creatures Inc. / GAME FREAK inc. 에 있습니다. 영리 목적으로 쓰지 마세요.


1. 받은 파일이 무엇인가요?
--------------------------
  Poke-Draft-Duel-Setup-0.1.0.exe     설치 마법사 (권장)
  Poke-Draft-Duel-portable.zip        설치 없이 쓰는 묶음 (압축을 풀어서 바로 실행)

둘 중 하나만 있으면 됩니다.


2. 설치 마법사로 설치하기
-------------------------
 (1) Poke-Draft-Duel-Setup-0.1.0.exe 를 더블클릭합니다.

 (2) "Windows에서 PC를 보호했습니다" 화면이 나오면 (처음 실행할 때 나올 수 있어요)
       - 글자 "추가 정보" 를 누릅니다.
       - 아래에 나타나는 "실행" 버튼을 누릅니다.
     이 경고는 설치 파일에 유료 코드 서명을 하지 않아서 뜨는 것입니다.
     바이러스가 있다는 뜻이 아닙니다. 파일을 믿을 수 있는 곳에서 받았을 때만 실행하세요.

 (3) 설치 마법사가 열리면 "다음"을 누릅니다.
 (4) 설치 위치를 고릅니다. 바꾸지 않아도 됩니다. (기본 위치는 아래 3번 참고)
 (5) "설치"를 누르고, 끝나면 "마침"을 누릅니다.
     "Poke Draft Duel 지금 실행"에 체크가 되어 있으면 바로 게임이 열립니다.

관리자 권한이 필요 없고, 현재 윈도우 계정에만 설치됩니다.


3. 설치된 파일은 어디에 있나요?
-------------------------------
기본 설치 위치:

  C:\Users\<내 사용자 이름>\AppData\Local\Programs\Poke Draft Duel\

이 폴더 안에 들어 있는 파일:

  poke-draft-duel-win_x64.exe    <-- 게임 실행 파일
  resources.neu                  게임 화면, 데이터, 포켓몬 그림, 음악이 묶인 파일 (지우면 실행이 안 됩니다)
  app.ico                        바로가기에 쓰는 아이콘
  Uninstall.exe                  제거 프로그램
  .tmp\window_state.config.json  창의 크기와 위치를 기억하는 파일 (게임을 처음 실행하면 생깁니다)

"AppData" 폴더는 윈도우가 기본으로 숨겨 둡니다. 탐색기에서 찾기 어렵다면:
  - 탐색기 주소창에 %LOCALAPPDATA%\Programs 를 입력하고 Enter 를 누른 뒤
    "Poke Draft Duel" 폴더를 엽니다.
  - 또는 바탕화면의 "Poke Draft Duel" 바로가기를 오른쪽 클릭하고
    "파일 위치 열기"를 누르면 이 폴더가 바로 열립니다.


4. 게임 실행하기 (설치한 경우)
------------------------------
다음 중 아무 방법이나 됩니다.

  A. 바탕화면의 "Poke Draft Duel" 아이콘을 더블클릭합니다.
  B. 시작 메뉴를 열고 "Poke Draft Duel"을 찾아 누릅니다.
     (시작 메뉴 폴더 안에 "제거" 바로가기도 있습니다.)
  C. 위 3번의 폴더에서 poke-draft-duel-win_x64.exe 를 직접 더블클릭합니다.

게임 창이 열리고 "시작하기" 화면이 나오면 정상입니다.
이 버전은 인터넷이 없어도 할 수 있습니다. 게임 데이터와 포켓몬 그림이 모두 들어 있습니다.


5. 설치 없이 쓰기 (포터블 zip)
------------------------------
 (1) Poke-Draft-Duel-portable.zip 을 오른쪽 클릭하고 "모두 압축 풀기"를 합니다.
     반드시 압축을 푼 뒤에 실행하세요. zip 안에서 바로 실행하면 안 됩니다.
 (2) 풀어낸 폴더 안에 두 파일이 같이 있어야 합니다. 둘을 따로 옮기지 마세요.
       poke-draft-duel-win_x64.exe
       resources.neu
 (3) poke-draft-duel-win_x64.exe 를 더블클릭합니다.
     (2번의 (2) 경고가 나오면 같은 방법으로 넘어가세요.)

바탕화면, 시작 메뉴 바로가기는 만들어지지 않습니다. 필요하면 exe 를 오른쪽 클릭해서
"바로 가기 만들기"를 하세요.


6. 게임이 안 열릴 때
--------------------
  - 창이 아예 안 뜨고 바로 꺼진다
      Windows 10 일부 PC에서는 "Microsoft Edge WebView2 런타임"이 필요합니다.
      "WebView2 Runtime" 으로 검색해 Microsoft 공식 페이지에서 설치한 뒤 다시 실행하세요.
      (Windows 11에는 대부분 이미 들어 있습니다.)
  - "Windows에서 PC를 보호했습니다" 화면이 나온다
      2번의 (2)처럼 "추가 정보" -> "실행".
  - 백신이 파일을 막거나 지운다
      서명이 없는 새 프로그램은 백신이 의심할 때가 있습니다. 파일을 받은 곳이 믿을 수 있는
      곳이면 백신의 예외 목록에 설치 폴더를 추가하고 다시 설치하세요.
  - 실행 파일을 찾을 수 없다
      3번의 폴더를 확인하세요. 설치 위치를 바꿨다면 그 위치에 있습니다.
      설치한 위치가 기억나지 않으면, 바탕화면 바로가기 -> 오른쪽 클릭 -> "파일 위치 열기".


7. 기록(연승, 설정)은 어디에 저장되나요?
-----------------------------------------
게임 기록은 설치 폴더가 아니라 윈도우의 WebView2 저장소에 들어갑니다.
  - 웹 버전(인터넷 주소로 하는 게임)과 기록이 공유되지 않습니다.
  - 제거(삭제)해도 기록이 남아 있을 수 있습니다.


8. 제거하기
-----------
  방법 1. 시작 메뉴 -> "Poke Draft Duel" 폴더 -> "제거"
  방법 2. 윈도우 설정 -> 앱 -> 설치된 앱 -> "Poke Draft Duel" -> 제거
  방법 3. 설치 폴더(3번)의 Uninstall.exe 를 실행

  설치 폴더 안의 .tmp 폴더는 남을 수 있습니다. 폴더 전체를 지워도 됩니다.
  포터블 버전은 폴더를 통째로 지우면 끝입니다.


9. 새 버전으로 바꾸기
---------------------
  새 설치 파일을 받아서 그대로 실행하면 같은 위치에 덮어 설치됩니다.
  (실행 중이면 게임을 먼저 끄세요. 이전 버전을 따로 지울 필요는 없습니다.)
  포터블은 기존 폴더 안의 poke-draft-duel-win_x64.exe 와 resources.neu 두 파일을
  새 것으로 바꾸면 됩니다.
